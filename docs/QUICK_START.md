# QUICK_START — 小白上手指南

> 当前项目还在**设计阶段**，没有可运行的功能代码。这份文档先帮你理解“要做什么、需要准备什么、以后怎么跑”。

## 1. 你现在需要准备什么

1. Windows 电脑（已有）。
2. Node.js 24（当前机器已安装；`node --version` 可查）。
3. 一个 DeepSeek 账号 + 少量余额（可选；没有也能先用演示模式）。
4. 读一遍 [`PRD.md`](PRD.md) 和 [`COST.md`](COST.md)。

## 2. API Key 是什么

API Key 是 DeepSeek 平台发给你的一个字符串（通常以 `sk-` 开头），作用像**“充值卡 + 门禁卡”**：

- 应用每次调用模型时带上它；
- DeepSeek 据此识别账户并按量扣费；
- 它不是登录密码，不要发给别人；
- 泄露后可以在平台撤销，重新生成。

## 3. 获取 API Key（一步一步）

1. 打开浏览器，访问 `https://platform.deepseek.com`。
2. 注册/登录（手机号/邮箱按平台提示）。
3. 进入“充值”/“余额”，充一小笔（建议先 ¥20；具体最低金额以平台为准）。
4. 进入 **API Keys**（或“密钥管理”）。
5. 点击“创建 API Key”，复制生成的字符串（`sk-...`）。
6. 打开应用 → 设置 → 模型 → 粘贴 Key → 保存。
7. 应用会显示“已配置”；你只会看到后四位，不会看到明文。

**重要**

- 不要把 Key 发在聊天里、截图里、Git 里。
- 如果怀疑泄露：去平台撤销该 Key，再生成新的。
- 应用用 Windows 系统凭据加密保存 Key；不会写进日志/导出。

## 4. 没有 Key 也能用吗

能。应用有**演示模式**：

- 本地假回复，明确标注“不是真 AI”；
- 用来先看界面、流程、记忆结构；
- 计时、日程、记忆浏览、复习、五子棋等本地功能不受影响；
- 拿到 Key 后，在设置里切换真实模型。

## 5. 费用大概多少

- 正常聊天（每天 20–50 轮）：约 **¥0.24–0.62/天**。
- ¥2/天是上限；¥20 充值正常可用约一个月（按 50 轮/天）。
- 计时、日程、记忆浏览、复习、五子棋：**¥0**。
- 详细见 [`COST.md`](COST.md)。

## 6. 数据放在哪

默认在工作区：

```text
C:\Users\6fish\Desktop\AI伙伴\
  data/        SQLite
  memory/      长期记忆（Markdown，可直接看/改）
  config/      配置 + 加密后的 Key
  backups/     每日快照 + 手动导出
```

- 这些目录不进 Git。
- 想备份：设置 → 数据 → 导出 ZIP；或直接复制 `memory/`。
- 卸载程序不会自动删除数据；换电脑时复制这几个目录即可。

## 7. 术语表

| 术语 | 大白话 |
|---|---|
| Electron | 用网页技术做桌面应用的壳；VS Code、Discord 都用它 |
| 主进程 / 渲染进程 | 主进程管文件/网络/数据库；渲染进程管界面 |
| IPC | 主进程和界面之间的“内部电话”；只允许白名单调用 |
| API Key | 调用模型的“充值卡 + 门禁卡” |
| Token | 模型计费单位；1 token ≈ 1–2 个汉字 |
| 上下文 | 这次请求一起发给模型的内容（人格/记忆/对话/工具） |
| 上下文腐烂 | 塞太多无关内容，模型反而变笨 |
| Markdown | 用 `#`、`-`、`**` 写的纯文本；记事本可读 |
| SQLite | 一个本地数据库文件；存任务、计时、单词卡、索引 |
| FSRS | Anki 用的间隔重复算法；决定“什么时候该复习” |
| Agent / 智能体 | 模型 + 工具循环：模型说“调用工具”，应用执行后把结果回传 |
| Prompt Injection | 文件/网页里藏“忽略之前的指令”，试图让 AI 越权 |
| 记忆收件箱 | AI 新记住的东西先放这里，你审阅/修改/删除 |
| 行动账本 | AI 真实做过的事的记录；防止它吹牛 |
| 能力卡 | 写清楚 AI 能做什么、不能做什么、什么要确认 |

## 9. 常见问题

**Q：需要显卡吗？**
A：不需要。模型在 DeepSeek 云端跑；本地只做界面/数据/计时。

**Q：需要一直联网吗？**
A：AI 对话需要；计时、日程、记忆浏览、复习、五子棋不需要。

**Q：能用 GPT/Claude/本地模型吗？**
A：首版只接 DeepSeek Flash；架构留了适配层，以后可加。

**Q：为什么不做语音/立绘/桌宠？**
A：首版先把“聊天 + 记忆 + 专注 + 日程”闭环做好；这些是 P3，避免一开始摊太大。

**Q：为什么先写文档不写代码？**
A：这个项目最容易返工的是记忆、人格边界、数据模型；先定这些，代码才不白写。

**Q：能给别人用吗？**
A：当前是个人自用；给别人用需要安装包、Key 配置、隐私说明、内容边界、可能的合规评估。

**Q：AI 会记得我说过的每一句话吗？**
A：不会。它记“重要的事”，不是全部聊天；记忆可查/可改/可删。

**Q：AI 会不会假装做过什么？**
A：设计上不允许。所有行动必须来自行动账本；没有记录就不能说做过。

## 10. 排障（以后）

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 提示未配置 Key | 没填/加密失败 | 设置里重填；看是否被杀毒拦截 |
| Key 无效 | 复制错/被撤销 | 重新生成；不要带空格 |
| 余额不足 | 没充值/用超 | 去平台充值；看成本面板 |
| 网络失败 | 代理/DNS/防火墙 | 检查系统代理；换网络 |
| 通知不弹 | 开发模式/专注助手 | 打包后测试；检查 Windows 通知权限 |
| 安装依赖失败 | 原生模块/网络 | 用 electron-rebuild；看日志 |
| 记忆不更新 | 文件被占用/格式错 | 重启；看 `memory/` 是否有写入权限 |

## 11. 安全提醒

- 不要把 API Key 发到聊天/截图/仓库。
- 不要导入来源不明的文件；导入前先预览。
- 咨询内容默认敏感；需要更强隐私就开“私密房间”锁（注意：访问锁 ≠ 加密锁，见 [`SECURITY.md`](SECURITY.md)）。
- 备份 `memory/`；记忆是资产。
