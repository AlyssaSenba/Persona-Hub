# QUICK_START — 小白上手指南

> 当前可运行的只有 **P0.5 人设调试器**（Node 服务 + 浏览器界面），完整 app 仍在设计阶段。这份文档说明需要准备什么、怎么跑、术语是什么意思。

## 1. 你现在需要准备什么

1. Windows 或 Linux 电脑。
2. Node.js ≥ 22（`node --version` 可查）和 npm；Git。
3. 一个现代浏览器（Edge / Chrome / Firefox）。
4. 一个 DeepSeek 账号 + 少量余额（可选；没有也能先用演示模式）。
5. 读一遍 [`PRD.md`](PRD.md) 和 [`COST.md`](COST.md)。

## 1.1 还需要下载什么

- **现在不用额外下载**。第一次运行会自动 `npm install`，依赖只有 React、Vite、TypeScript 等纯 JS 包，不需要编译工具链。
- Windows 的 PowerShell 可能禁止 `npm.ps1`：用 `npm.cmd` 或 `cmd /c npm`，不需要改系统策略。
- 不需要：Python、Visual Studio Build Tools、Rust、Docker、Unity、pnpm、OCR/TTS 服务。
- 可选：VS Code（看/改代码）。
- DeepSeek API Key 不是下载，去平台创建；没有也能演示模式。

## 2. API Key 是什么

API Key 是 DeepSeek 平台发给你的一个字符串（通常以 `sk-` 开头），作用像**“充值卡 + 门禁卡”**：

- 应用每次调用模型时带上它；
- DeepSeek 据此识别账户并按量扣费；
- 它不是登录密码，不要发给别人；
- 泄露后可以在平台撤销，重新生成。

## 3. 获取 API Key（一步一步）

1. 打开浏览器，访问 `https://platform.deepseek.com`。
2. 注册/登录（手机号/邮箱按平台提示）。
3. 进入“充值”/“余额”，充一小笔（建议先 ¥20；具体最低金额以平台为准）。
4. 进入 **API Keys**（或“密钥管理”）。
5. 点击“创建 API Key”，复制生成的字符串（`sk-...`）。
6. 打开应用 → 设置 → 模型 → 粘贴 Key → 保存。
7. 应用会显示“已保存”；不会回显明文。

**重要**

- 不要把 Key 发在聊天里、截图里、Git 里。
- 如果怀疑泄露：去平台撤销该 Key，再生成新的。
- 当前版本只把 Key 保存在本次 Node 进程内存，不落盘，重启服务要重填。
- 如果你在平台上看到已有的 “DeepSeek Harness” Key：那是当前工具自己用的，**不要复用它，也不要删除它**；给 AI伙伴 新建一个专用 Key。

## 4. 没有 Key 也能用吗

能。应用有**演示模式**：

- 本地假回复，明确标注“不是真 AI”；
- 用来先看界面、流程、记忆结构；
- 计时、日程、记忆浏览、复习、五子棋等本地功能不受影响；
- 拿到 Key 后，在设置里切换真实模型。

## 5. 费用大概多少

- 正常聊天（每天 20–50 轮）：约 **¥0.24–0.62/天**。
- ¥2/天是上限；¥20 充值正常可用约一个月（按 50 轮/天）。
- 计时、日程、记忆浏览、复习、五子棋：**¥0**。
- 详细见 [`COST.md`](COST.md)。

## 6. 数据放在哪

当前 P0.5 只会在项目根目录写：

```text
config/
  web-settings.json     称呼、关系、安全词、演示模式、已启用 patch（不含 API Key）
  persona-patches/      每个人设 patch 一个 JSON 文件
```

- `config/` 不进 Git；备份直接复制它即可。`persona.md` 只读，不会被改。
- 请在项目根目录启动服务，否则会在别处生成 `config/`。
- 完整 app（P1+）计划再增加 `data/`（SQLite）、`memory/`（Markdown 长期记忆）、`backups/`，同样不进 Git。

## 6.1 称呼与调试模式

- 首次设置：AI 的名字（必填）、可选的 AI 昵称、你的名字/昵称、你希望怎么被称呼（名字/昵称/你/您）。
- 调试模式：
  - 入口：设置里自定义的**安全词**、快捷键/特殊 key、设置页。
  - 打开后 AI 会暂时跳出角色，帮你改语气/称呼/主动性/情绪强度等。
  - 流程：输入指令 → 生成 patch → 预览 3–5 轮 → 应用/回滚。
  - 不能关闭安全/内容/危机边界；安全词不发给模型。
- 调试模式默认隐藏，不影响普通聊天。

## 7. 术语表

| 术语 | 大白话 |
|---|---|
| 后端 / 前端 | 后端是本地 Node 服务，管文件/网络/模型调用；前端是浏览器里的界面 |
| SSE | 服务端一边生成一边把文字推给界面的流式协议 |
| API Key | 调用模型的“充值卡 + 门禁卡” |
| Token | 模型计费单位；1 token ≈ 1–2 个汉字 |
| 上下文 | 这次请求一起发给模型的内容（人格/记忆/对话/工具） |
| 上下文腐烂 | 塞太多无关内容，模型反而变笨 |
| Markdown | 用 `#`、`-`、`**` 写的纯文本；记事本可读 |
| SQLite | 一个本地数据库文件；存任务、计时、单词卡、索引 |
| FSRS | Anki 用的间隔重复算法；决定“什么时候该复习” |
| Agent / 智能体 | 模型 + 工具循环：模型说“调用工具”，应用执行后把结果回传 |
| Prompt Injection | 文件/网页里藏“忽略之前的指令”，试图让 AI 越权 |
| 记忆收件箱 | AI 新记住的东西先放这里，你审阅/修改/删除 |
| 行动账本 | AI 真实做过的事的记录；防止它吹牛 |
| 能力卡 | 写清楚 AI 能做什么、不能做什么、什么要确认 |
| 安全词 | 你在设置里定的短语；在聊天中输入它打开调试模式 |
| Patch | 对人设的叠加修改；可预览/回滚 |
| 调试模式 | 暂时跳出角色，改语气/称呼/情绪强度；不关闭安全边界 |

## 8. 运行 P0.5 人设调试器（当前可用）

### 8.1 一键启动

- **Windows**：双击根目录的 `start-persona-lab-web.cmd`。
- **Linux / macOS**：在项目根目录运行 `./start-persona-lab-web.sh`。

脚本会按需 `npm install`，构建前端，启动本地服务并打开浏览器：

```text
http://127.0.0.1:4173
```

### 8.2 手动启动

```bash
npm install        # 首次
npm run build
npm start
```

Windows PowerShell 里把 `npm` 换成 `npm.cmd`。

- 需要 Node ≥ 22；服务只监听 `127.0.0.1`，不要暴露到局域网/公网。
- 端口可用 `PORT=5000 npm start` 修改；`NO_OPEN=1` 则不自动打开浏览器（Windows cmd 用 `set`，PowerShell 用 `$env:NO_OPEN=1`）。
- 如果没有自动弹出浏览器（比如没有图形界面），手动访问上面的地址。
- API Key 只保存在本次 Node 进程内存，**不落盘**；重启服务要重填。
- 关闭命令行窗口 / `Ctrl+C` = 关闭服务。

### 8.3 首次运行设置

1. 点“设置”，填 AI 名字、你的名字/称呼、关系；
2. 没有 Key 就保持“演示模式”，先看界面；
3. 有 Key：设置 → DeepSeek API Key → 粘贴 → 取消“演示模式” → 保存；
4. 聊天；点“调试人设”或按 `Ctrl+Shift+D` 调语气。

- P0.5 没有记忆/日程/专注；完整 app 见 P1。
- **不要把 Key 发到聊天/截图/Git**。

## 9. 常见问题

**Q：需要显卡吗？**
A：不需要。模型在 DeepSeek 云端跑；本地只做界面/数据/计时。

**Q：需要一直联网吗？**
A：AI 对话需要；计时、日程、记忆浏览、复习、五子棋不需要。

**Q：能用 GPT/Claude/本地模型吗？**
A：首版只接 DeepSeek Flash；架构留了适配层，以后可加。

**Q：为什么不做语音/立绘/桌宠？**
A：首版先把“聊天 + 记忆 + 专注 + 日程”闭环做好；这些是 P3，避免一开始摊太大。

**Q：为什么先写文档不写代码？**
A：这个项目最容易返工的是记忆、人格边界、数据模型；先定这些，代码才不白写。

**Q：能给别人用吗？**
A：当前是个人自用；给别人用需要安装包、Key 配置、隐私说明、内容边界、可能的合规评估。

**Q：AI 会记得我说过的每一句话吗？**
A：不会。它记“重要的事”，不是全部聊天；记忆可查/可改/可删。

**Q：AI 会不会假装做过什么？**
A：设计上不允许。所有行动必须来自行动账本；没有记录就不能说做过。

## 10. 排障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 提示未配置 Key | 没填，或服务重启过（Key 只存内存） | 设置里重填 |
| Key 无效 | 复制错/被撤销 | 重新生成；不要带空格 |
| 余额不足 | 没充值/用超 | 去平台充值；看成本面板 |
| 网络失败 | 代理/DNS/防火墙 | 检查系统代理；换网络 |
| 页面显示“还没有构建前端” | 没执行 `npm run build` | 先构建再启动 |
| 端口被占用 | 4173 已有进程 | 换端口：`PORT=5000 npm start` |
| 浏览器没自动打开 | 无图形界面 / 缺 `xdg-open` | 手动访问 `http://127.0.0.1:4173` |
| 安装依赖失败 | 网络 / Node 版本过低 | 检查网络和代理；确认 Node ≥ 22 |
| 记忆不更新 | 文件被占用/格式错 | 重启；看 `memory/` 是否有写入权限 |

## 11. 安全提醒

- 不要把 API Key 发到聊天/截图/仓库。
- 不要导入来源不明的文件；导入前先预览。
- 咨询内容默认敏感；需要更强隐私就开“私密房间”锁（注意：访问锁 ≠ 加密锁，见 [`SECURITY.md`](SECURITY.md)）。
- 备份 `memory/`；记忆是资产。
