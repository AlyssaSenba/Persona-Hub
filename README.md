## P0.5 快速运行

需要 Node.js ≥ 22 和 npm，以及一个现代浏览器。

### 一键启动

- **Windows**：双击 [`start-persona-lab-web.cmd`](start-persona-lab-web.cmd)。
- **Linux / macOS**：运行 `./start-persona-lab-web.sh`。

脚本会按需安装依赖、构建前端、启动本地服务并打开：

```text
http://127.0.0.1:4173
```

### 手动启动

```bash
npm install
npm run build
npm start          # 没有图形界面时手动访问上面的地址
```

Windows PowerShell 里把 `npm` 换成 `npm.cmd`。可用环境变量 `PORT`（默认 4173）改端口，`NO_OPEN=1` 不自动打开浏览器。

- 服务只监听 `127.0.0.1`，没有鉴权，不要暴露到局域网 / 公网。
- API Key 优先从根目录 `.env` 实时读取（改完不用重启）；设置页临时填的只保存在 Node 进程内存，**不落盘**，重启要重填。
- 关闭命令行窗口（或 `Ctrl+C`）= 关闭服务。
- 其他脚本：`npm run typecheck` 做类型检查。

### 首次设置

- 首次打开：点“设置”，填 AI 名字、称呼、关系，保存。
- 可选“关于你”：国籍/所在地、性别（可填“无性别”）、特殊注意事项；只用来调语气和分寸，不填也行。对话里说的下一轮生效，要长期保留回设置保存。
- 关系选“家人”后，可以再设“他该叫你什么”（按性别给选项；性别不填或“无性别”时给全部）。它只改称呼，不改关系。
- 接真实模型（推荐）：把 `DEEPSEEK_API_KEY=...` 写进根目录 `.env`，服务端每次请求实时读取，改完不用重启；`.env` 已 gitignore。也可以设置页临时填 Key（仅本次 Node 内存），`.env` 优先。
- 调人设：点“调试人设”，或按 `Ctrl+Shift+D`；也可以设置一个安全词，在聊天里输入它打开。
- 当前范围：只调聊天语气/称呼/情绪/主动性；没有记忆、日程、专注等模块。

## 这是什么

这不是“一个聊天机器人 + 六个功能页”，而是：

> **一个固定人格的本地伙伴 + 一套它能调用的生活工具。**

功能是“房间”，AI 只有一个。记忆是它的“人生”，工具是它的“手脚”，提示词是它的“性格与边界”。

它明确知道自己是 AI、运行在这台电脑里；它可以有情绪色彩和态度，但不会假装有现实身体、不会虚构“我为你做了什么”、不会承诺做不到的事。

## 核心原则

1. **一个灵魂，多个房间**
   日常聊天、专注、外语、日程、心理咨询、技能学习、小游戏共享同一份人格、关系和长期记忆；不同房间只切换工具和上下文重点。

2. **记忆可见、可改、可删**
   长期记忆以 Markdown 文件保存在工作区，用户可以直接查看和编辑；SQLite 只做检索索引。AI 自动写入，但写入内容进入“记忆收件箱”，可审阅、修改、撤销。

3. **能力诚实，不假承诺**
   所有“我做了什么”必须来自真实的工具调用记录（行动账本）。能力卡明确列出能做什么、不能做什么、哪些操作需要确认。

4. **上下文有预算**
   不把 1M 上下文塞满；每轮只带高信号内容，旧对话压缩归档，按需检索。目标是把“聊久了变笨、变贵”变成“有边界、可检测、可修正”。

5. **渐进式设定**
   首次启动只设 3 件事：你的称呼、AI 的名字/性别/性格、关系。其他模块先标“待设定”，点进去再设。

6. **温暖但不操控**
   可以有情绪、有偏好、有不同意见；不制造愧疚、不威胁、不鼓励用户疏远现实关系。

## 技术栈

**当前已实现（P0.5）**

- **前端**：React 19 + TypeScript + Vite 8，手写 CSS
- **后端**：Node ≥ 22 内置 `node:http`，无框架、无原生依赖；直接运行 `.mts`
- **模型**：DeepSeek `deepseek-flash`（OpenAI 兼容接口，流式 SSE）
- **平台**：Windows、Linux（macOS 理论可用，未验证）

**计划（P1+，均未锁定，搭骨架前先做最小验证）**

- 桌面壳：Tauri 或正式签名 Electron（托盘、自启、系统通知）
- 数据：Markdown（记忆真相源）+ SQLite（结构化数据与索引，驱动待验证）
- UI：Tailwind CSS + shadcn/ui + Motion；状态：Zustand
- 编排：Vercel AI SDK + 自建 DeepSeek 适配层
- 校验：Zod

详见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 数据放在哪

运行数据放在项目根目录（启动服务时的工作目录）：

```text
Persona-Hub/
  config/        运行时配置（当前：web-settings.json、persona-patches/；不含 Key）
  .env           本地密钥（gitignored）
  .env.example   密钥模板（可提交）
  persona.md     人设（只读；应用读取它作为核心人设）
  docs/          文档
  server/        Node 服务
  src/           前端与共享类型
  out/           构建产物
```

P1+ 计划再增加 `data/`（SQLite）、`memory/`（Markdown 长期记忆）、`backups/`。
`config/`、`data/`、`memory/`、`backups/`、`out/`、`.env` 已在 `.gitignore` 中排除，避免隐私进入 Git。

## 路线图

- **P0 设计定稿（当前）**：PRD、架构、数据模型、记忆策略、安全与内容边界。
- **P0.5 人设调试器（已实现）**：先单独调性格，不含完整模块；调顺后再进 P1。
- **P1 可运行垂直切片**：首次引导 + 聊天 + 记忆文件夹/记忆浏览器 + 专注计时 + 简单日程提醒。
- **P2 学习与规划**：外语练习、技能学习、更完整的日程与条件任务。
- **P3 深度模块**：心理咨询、小游戏、桌宠/立绘、语音、环境音等。

## 给第一次接触这个项目的人

- 不需要游戏引擎（Unity/Unreal）；当前是本地 Node 服务 + 浏览器，之后会做成桌面应用。
- 不需要一上来上 LangChain/LangGraph；“智能体”本质是“模型 → 工具调用 → 应用执行 → 结果回传”的循环。
- 不需要先学完所有技术；按 [`docs/QUICK_START.md`](docs/QUICK_START.md) 的术语表开始即可。
