# AI伙伴

> 一个住在你电脑里的、记得你、有边界的 AI 伙伴。

## 这是什么

这不是“一个聊天机器人 + 六个功能页”，而是：

> **一个固定人格的本地伙伴 + 一套它能调用的生活工具。**

功能是“房间”，AI 只有一个。记忆是它的“人生”，工具是它的“手脚”，提示词是它的“性格与边界”。

它明确知道自己是 AI、运行在这台电脑里；它可以有情绪色彩和态度，但不会假装有现实身体、不会虚构“我为你做了什么”、不会承诺做不到的事。

## 核心原则

1. **一个灵魂，多个房间**
   日常聊天、专注、外语、日程、心理咨询、技能学习、小游戏共享同一份人格、关系和长期记忆；不同房间只切换工具和上下文重点。

2. **记忆可见、可改、可删**
   长期记忆以 Markdown 文件保存在工作区，用户可以直接查看和编辑；SQLite 只做检索索引。AI 自动写入，但写入内容进入“记忆收件箱”，可审阅、修改、撤销。

3. **能力诚实，不假承诺**
   所有“我做了什么”必须来自真实的工具调用记录（行动账本）。能力卡明确列出能做什么、不能做什么、哪些操作需要确认。

4. **上下文有预算**
   不把 1M 上下文塞满；每轮只带高信号内容，旧对话压缩归档，按需检索。目标是把“聊久了变笨、变贵”变成“有边界、可检测、可修正”。

5. **渐进式设定**
   首次启动只设 3 件事：称呼、AI 性别与性格、关系。其他模块先标“待设定”，点进去再设。

6. **温暖但不操控**
   可以有情绪、有偏好、有不同意见；不制造愧疚、不威胁、不鼓励用户疏远现实关系。

## 计划中的技术栈

- **桌面**：Electron + React + TypeScript
- **构建**：electron-vite + electron-builder
- **UI**：Tailwind CSS + shadcn/ui + Motion
- **状态**：Zustand（本地 UI 状态）+ 主进程服务（业务状态）
- **数据**：Markdown（记忆真相源）+ SQLite（结构化数据与索引）
- **模型**：DeepSeek `deepseek-flash`（OpenAI 兼容接口；思考模式、工具调用、视觉、搜索）
- **编排**：Vercel AI SDK + 自建 DeepSeek 适配层（处理 `reasoning_content` 与工具调用的兼容性）
- **校验**：Zod（IPC、工具参数、外部数据）

> 技术栈是计划，不是既成事实；真正搭骨架时会先做最小验证（SQLite 原生模块、思考模式 + 工具调用、Windows 通知）。

## 数据放在哪

所有运行数据默认放在工作区：

```text
C:\Users\6fish\Desktop\AI伙伴\
  data/          结构化数据（SQLite）
  memory/        长期记忆（Markdown，可直接看/改）
  config/        配置与加密后的 API Key
  backups/       每日自动快照与手动导出
  docs/          文档
  src/           代码（后续）
```

`data/`、`memory/`、`config/`、`backups/` 已在 `.gitignore` 中排除，避免隐私进入 Git。

## 路线图

- **P0 设计定稿（当前）**：PRD、架构、数据模型、记忆策略、安全与内容边界。
- **P1 可运行垂直切片**：首次引导 + 聊天 + 记忆文件夹/记忆浏览器 + 专注计时 + 简单日程提醒。
- **P2 学习与规划**：外语练习、技能学习、更完整的日程与条件任务。
- **P3 深度模块**：心理咨询、小游戏、桌宠/立绘、语音、环境音等。

## 给第一次接触这个项目的人

- 不需要游戏引擎（Unity/Unreal）；这是一个桌面应用。
- 不需要一上来上 LangChain/LangGraph；“智能体”本质是“模型 → 工具调用 → 应用执行 → 结果回传”的循环。
- 不需要先学完所有技术；按 [`docs/QUICK_START.md`](docs/QUICK_START.md) 的术语表开始即可。
